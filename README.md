## Rationale

Python is one of the most widely used programming languages due to its combination of simplicity and versatility. Its clear and readable syntax makes it accessible to beginners, while its extensive ecosystem of libraries supports advanced applications in data science, artificial intelligence, web development, and scientific computing. Python is also commonly used as a “glue language”, enabling different tools and frameworks to be integrated into coherent computational workflows.

In the biomedical and health-related domains, Python has become a foundational technology. Many state-of-the-art research tools and frameworks rely on Python, including libraries for computational biology, neuroimaging, medical image processing, and deep learning. Large collaborative initiatives in medical AI also build on Python to ensure reproducible, open, and efficient research workflows.

## Aim and objectives

The course provides a solid foundation in Python programming for scientific applications. It is designed to enable participants to read, write, and modify code independently, even in complex research contexts.

The course starts from basic syntax and progressively introduces more advanced concepts such as data types, classes, and objects, which are essential for the effective use of scientific libraries. Particular attention is given to data handling and type conversions, which are critical when integrating multiple computational tools within a single workflow.

No prior programming experience is assumed. By the end of the course, participants will be able to write Python scripts, manipulate data, visualize results, and apply Python libraries to solve basic scientific problems.

### Specific objectives

At the end of the course, participants will be able to:

* acquire practical programming skills applicable to research and professional activities;
* understand the fundamentals of Python programming;
* write, run, and debug simple Python programs;
* work more independently in developing and modifying scientific code;
* read and adapt code generated or suggested by automated assistants such as large language models.

## Target audience and prerequisites

The course is open to anyone working with data who is interested in learning the fundamentals of scientific programming.

**Recommended prerequisites:**

* basic familiarity with data analysis concepts.

The course is delivered in English. The maximum number of participants is limited.

## Learning assessment

Learning outcomes are assessed through a compulsory practical test at the end of the course. Participants are required to write a simple program, modify existing code, and debug common syntax errors. An event evaluation questionnaire is also administered.

## Certificates

Participants may request a certificate of attendance. The certificate, including the total number of training hours, is issued to participants who have attended at least 80% of the course and achieved a minimum score of 75% in the final assessment.
